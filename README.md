## 📖 Overview

This repository serves as a curated collection of machine learning implementations, structured algorithm by algorithm. It is designed for developers and students who want to focus on specific models in isolation. 

Unlike complex end-to-end pipelines, each project here focuses on a single algorithm, making it ideal for targeted practice and understanding the mathematical foundations of individual models.

## 📂 Repository Structure

The projects are organized by algorithm type to facilitate easy navigation:

| Algorithm / Folder | Description |
| :--- | :--- |
| **[Linear Regression](./Linear%20Regression)** | Implementation of regression models for predicting continuous variables. |
| **[Logistic Regression](./Logistic%20Regression)** | Binary classification problems and probability estimation. |
| **[Support Vector Machine](./Support%20Vector%20Machine)** | Classification and regression analysis using SVMs for high-dimensional spaces. |

## 🛠️ Tech Stack

* **Language:** Python 3.x
* **Core Libraries:**
    * `pandas` & `numpy` (Data Manipulation)
    * `matplotlib` & `seaborn` (Visualization)
    * `scikit-learn` (Model Implementation)
* **Environment:** Jupyter Notebooks

## 🚀 Getting Started

To explore these projects locally:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/ikartiksavaliya/Machine-learning-one-by-one-projects.git](https://github.com/ikartiksavaliya/Machine-learning-one-by-one-projects.git)
    cd Machine-learning-one-by-one-projects
    ```

2.  **Navigate to a specific algorithm folder:**
    ```bash
    cd "Linear Regression"
    ```

3.  **Launch Jupyter Notebook:**
    ```bash
    jupyter notebook
    ```
